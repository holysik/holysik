## 🔧 Projects

### 📌 Devlog — 개발자 블로그 & 커뮤니티
> 개발자의 기술 기록과 성장 과정을 함께 담는 플랫폼

* **실시간 채팅** : STOMP 기반 1:1 및 그룹 실시간 채팅, 메세지 CRUD, 이미지 전송, 메세지 공감 등 채팅 구조 설계
* **이벤트 알림** :  좋아요, 댓글, 팔로우, 언급 이벤트 발생 시 실시간 알림 시스템 구현
* **회원 및 자동화** : 사용자 활동 기반 동적 등급 관리 및 Spring Scheduler 기반 메일 자동 발송 구현
* **콘텐츠 관리** : 플랫폼 건전성 유지를 위한 부적절한 콘텐츠 및 사용자 신고·접수 기능 개발
* **데이터 모델링** : 데이터 무결성과 확장성을 고려한 요구사항 분석 및 정규화 기반 데이터베이스(ERD) 설계
