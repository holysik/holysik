##  더 나은 시스템을 향해 도전하며, 끊임없이 성장을 추구하는 개발자 이규식입니다.

눈에 띄는 결과보다 **꾸준히 완성해 나가는 과정**을 중요하게 생각합니다.  
Java · Spring 기반의 백엔드 개발을 중심으로  
기능 하나하나가 **서비스 전체 흐름 속에서 어떻게 동작하는지**를 고민하며 개발하고 있습니다.

단순히 동작하는 코드가 아니라,  
**유지보수 가능하고 신뢰할 수 있는 구조**를 만드는 것을 목표로 합니다.  
팀과의 소통을 통해 더 나은 방향을 찾고,  
작은 개선이 쌓여 큰 안정성을 만든다고 믿습니다.
